# DirectXGame

DirectX11を使用して作成したC++のゲームプロジェクトです。

## 概要
このプロジェクトでは、DirectXを用いた基本的な描画処理やウィンドウ管理を実装しています。

## 主な機能
- ウィンドウ生成
- DirectX11による描画
- シェーダーの使用（HLSL）
- 頂点バッファの作成と描画

## 使用技術
- C++
- DirectX11
- Visual Studio

## 実行方法
1. Visual Studioで `GAME.sln` を開く
2. ビルドして実行
