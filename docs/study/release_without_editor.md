# Releaseビルドからエディタを外す(勉強資料)

2026-10-25。Releaseにも、エディタ(ImGuiのパネル)が出ていたので、**実行用のビルドとして、エディタ無しで動く**ようにした。

## 1. 用語
| 用語 | 意味 |
|---|---|
| `ENABLE_EDITOR` | エディタ(ImGuiのデバッグパネル)を有効にするコンパイル時のスイッチ(プリプロセッサのマクロ)。定義されているビルドでだけ、ImGuiが初期化されて、描かれる。 |
| ImGuiのコンテキスト | ImGuiが内部で持つ状態。作らずに`ImGui::GetIO()`などを呼ぶと、落ちる。 |

## 2. やったこと
1. **Releaseの設定から`ENABLE_EDITOR`を外した**(`GAME.vcxproj`。Debugには残す)。これで、Releaseでは、パネルも、`DebugEditor`も、`EditorUi`も、動かない。
2. **ImGuiを呼んでいた、ゲーム本体の箇所を直した**(エディタが無いと、コンテキストが無く落ちるため):
   - 「カーソルがImGuiのパネルの上か」の判定(`BuildController`・`RoadSystem`)は、`IsMouseOverEditorUi()`(`DebugTools/EditorGuard.h`)に置き換えた。エディタが無いビルドでは、常にfalse。
   - 各システムのデバッグパネル(City Stats・Time・Economy・Scenario・Profiler・Log・Build)の描画を、`ENABLE_EDITOR`の中に入れた。
3. **デバッグ表示を、Releaseでは出さない**: 建物と道路の接続線は、エディタ有りのビルドだけ。格子線は、エディタ有りでは、メニューのスイッチ。Releaseでは、建物・道路を置こうとしている間だけ。
4. **ImGuiのボタンでしか出来なかった操作に、代わりを用意した**: フリーハンドの道路の「確定/取消」ボタンは、ImGui。Releaseでは、クリック・Enter・Spaceで確定(置ける・払える時だけ)、右クリック・Escで取消。

## 3. 確認した方法
- Debug・Release、どちらもビルドが通る(Releaseは、`ENABLE_EDITOR`無しでコンパイルされる)。
- Releaseを、診断用の一時コード(削除済み)で動かして、タイトル画面→ゲーム→建物の配置→配置ツールをやめる→メニューを開く、まで落ちずに動くこと、画面にエディタのパネルが映らないこと、格子線が配置中だけ出ることを、画面を保存して確認した。

## 4. 見つけた問題と注意点
| 問題 | 内容 |
|---|---|
| `ImGui::GetIO()`が、ゲームの動作の中に混ざっていた | 「パネルの上でクリックしても、街に抜けない」ための判定が、ゲーム本体の中に直接書いてあった。エディタを外すと落ちるので、エディタの有無を隠す関数に置き換えた。**ゲーム本体のコードに、ImGuiを直接書かない**ことが、今後の注意。 |
| 以前のバックログの記載は古かった | 「Releaseで動作しない可能性」と書いてあったが、その後`ENABLE_EDITOR`がReleaseにも定義されていたため、問題が見えていなかった。外して初めて、上の判定が見つかった。 |

## 5. 今は、やらないこと(割り切り)
- フリーハンドの道路の、画面上の確定ボタン(Releaseは、クリック・Enterで確定)。HUDと同じスキンで、ボタンを作るのが、次の段階。
- Releaseでのデバッグ機能の一括の外し方の見直し(`Debug::Log`のログ出力など。今は、そのまま)。
