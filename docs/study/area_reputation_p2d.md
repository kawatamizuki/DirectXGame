# P2-D: 評判(勉強メモ)

## 1. 何を作ったか
商業エリアの区画ごとの「評判」。週末に、目標値へ少しずつ近づける。計画を守っているか(計画の履行)と、住民が実際に使えているか(実際の利用)を、別々に評価して、目標値にする。

## 2. 設計の要点
- **現在の状態で評価する**: 過去の最高到達(achieved)は、履歴として残すだけ。4店舗の最低進捗に一度届いて、2店舗に減ったら、今は未達。
- **猶予を区別する**: 初回の開発猶予(周知から)と、再整備の猶予(最低進捗を下回ってから)は別。再整備の猶予の計測は、最低進捗を続けて保つまで取り消さない(一時的な操作で引き延ばせない)。
- **目標へ近づける方式**: 目標値(1.0 + 計画の項 + 利用の項)へ、1週の上限つきで近づく。急な減点が無く、回復もゆっくり。成功率が100%でも、目標が頭打ちなので、上がり続けない。
- **悪循環を避ける**: 来訪者数・売上は使わない。評判が下がる → 客が減る → さらに下がる、が起きない。
- **満たされていても減点しない**: 需要への貢献は、標準の回復量との比で、0になる割合(0.5)以下は 0。満たされた住民の娯楽的な利用に、価値を残す。
- **耐久試験でも動く**: 住民の更新の週末の処理から呼ぶ(画面のフレームには依存しない)。

## 3. 見つけたこと(診断用の街 26週)
- 成功率: 通算で 100%(181/181)。週ごとの値は 0.88〜1.12 でぶれる。週をまたぐ外出(出発と利用が別の週)のためで、実際の失敗ではない。補助的な指標にした理由。
- 需要への貢献: 週ごとに 0.43〜0.6(区画A)。標準の回復量の約半分で、0になる割合の 0.5 の付近。住民の需要が、すでにある程度満たされているため。
- 評判の例: 4店の区画A(最低進捗を満たす): 猶予中に利用評価で 1.02 前後へ上がり、猶予後は計画規模がそろっているため 1.06〜1.10 で安定。2店の区画B(最低進捗未満): 猶予中は 1.00〜1.03、猶予後に 1週 -0.03 ずつ下がって、第20週ごろ 0.80(目標)に収束。

## 4. 見つけた問題
- テストで、「猶予が終わる週」の数え方が1週ずれた(周知の週から数えて graceWeeks 週目に、猶予が終わる)。
- 成功率の項と需要の項を同時に与えると、需要の加点が減点を打ち消す。テストでは、需要の貢献を0にして確認した。
