# 道路の部分解体(Gate 2): スライスで切る・平らな切り口・住民の経路の整え

## 作ったもの
解体ツールで、建物に加えて、**道路**も、クリック(・なぞって)選んで、離すと切り取れる。道路は「道路に沿った、長さ0.5(マス1つぶん)×道幅」のスライス単位。費用は、切り取った道路の建設費の半額。切った跡の、住民の経路・満足度・青マスも整える。(Gate 2のテストは、直線道路。斜め・曲線・交差点は、同じ計算で動くが、Gate 3で、確認・調整する)

## 設計の判断と、その理由

### 1. 切り取りは「純粋な計算」に分けた(`Field/RoadCutting`)
- 画面・ゲームの状態を知らず、道路の区間の一覧と、切り取る範囲(`RoadCutWindow`)だけで、結果が決まる。単体テストできる(`cut_test`)。
- **範囲の中にある、全ての道路の中心線を切る**(Liang-Barskyの線分クリップ)。同じ道路の途中も、交わる別の道路も、同じ規則。→ 交差点では、選んだ範囲の中にある、各道路の該当部分だけが消える(Q2)。
- 区間ごとに、当たった範囲を集め、重なる・つながる範囲を1つにまとめ、残る部分を、新しい区間にする。同じスライスを何度足しても、同じ結果(多重請求の防止)。
- **切っていない側の端は、元の点・元の印のまま**(ビット単位で同じ)。だから、道路ノード(端点の一致で、つながりを判定する)が、壊れない。

### 2. スライスの境目は、区間の始点から、マス1つぶんおき(格子の線の上)
- 直線は、始点が「格子の交点」なので、スライスの境目(始点 + m×0.5)が、画面のマス目の線に揃う。斜め・曲線でも、道路の向きに揃った長方形になる。
- **行き止まりの見た目の延長(0.5)は、端のスライスに含める**。(延長だけを指しても、中心線が何も切れない、ということが無いように。端のスライスを切ると、延長も一緒に消える。ハイライトも、延長を含めて出す)。切った跡の端も、格子の線の上になる。
- 【修正(2026-10-28)】最初は、スライスを「始点を中心に」並べていた(マスの中心から引く前提)。格子の交点から引くようにした後、スライスが、マス目をまたいで見えた(2つのマスの間)ので、境目を格子の線に揃えた。
- マウスの下の道路は、「中心線から、道幅の半分以内」(`FindNearestPointOnRoad`)で当てる。

### 3. 短すぎる端切れは、捨てる(マスの1/4未満)
- 切った時に、ごく短い残りが出ると、微小な区間・ノードが増え、見た目も壊れる。そこで、下限(マスの1/4)より短い残りは、**捨てる**。捨てた分も、取り除いた長さ(=費用)に入れる(見えない所で、勝手に消えない・払い忘れない)。
- 長さの合計は、いつも「残った分+取り除いた分=元の長さ」(テストで確認)。

### 4. 切り口は、平らに描く(`RoadSegment::flatStart/flatEnd`)
- 道路メッシュは、行き止まりの見た目を、マスの半分(0.25)だけ、伸ばす(直線の端点がマスの中心にあるため)。切り口も行き止まりなので、**そのままだと、両側が0.25ずつ伸びて、0.5のスライスが、見た目だけ塞がる**。
- 切った端には、印(`flat`)を付け、メッシュと占有の矩形で、延長をしない。通常の道路の建設は、常にfalse(影響しない)。セーブには、切り口だけを書く(印が無い古いセーブは、そのまま読める)。
- 道路が分割された点(T字路の接続)は、平らではないので、`SplitSegmentAt`で、印を引き継がないようにした。

### 5. 切った後に作り直す物
- 区間 → 道路ノード(端点の一致から) → メッシュ(1回) → 占有(道路と建物から全部) → 青マス。
- **青マス**: 切り取った範囲を、道の両脇の列まで広げた四角と重なるマスを消す。ただし、**建っている建物の敷地にかかるマスは、残す**(`RemoveCellsOverlappingExcept`)。道路の連なりの情報を保存していないので、残りの道の青マスを作り直すことは、しない(制限事項)。

### 6. 住民の経路(Q5。暫定の仕様。数値は、`ResidentSimSettings`で調整できる)
- 道路区間の添字が変わるので、全員の「通る区間の添字」(混雑表示用)を空にする。
- 歩いている・施設の中にいる住民のうち、**これから通る経路が、取り除いた部分を通る人**だけを対象にする(通らない人は、そのまま)。経路は道路の中心線をたどるので、中心線(細い四角)が、取り除いた部分と交わるかで判定する。
- 対象の住民は、今の外出をやめて、帰宅を優先する。今の位置の近くの、残った道路から、自宅(家が無ければ、元の家の位置)への経路を、探し直す(`PlanRoute`)。
  - **帰れる**: 経路の先頭が、今の位置なので、位置は飛ばない。体力を消費し(通常の移動と同じ、道のりあたりの消費 × 倍率)、満足度が下がる。
  - **帰れない**: 立ち往生(`Stranded`)。道路の上で立ち往生する(今の位置が道路の上ならそのまま。切り取られた跡・施設の中なら、近くの、残った道路の上へ寄せる。寄せる範囲は、数マス。ワープはしない)。動かず、施設も使わない。満足度が、もっと下がる。
- **施設の中にいる住民は、道路が切られても、そのまま利用を続ける**(利用が終わるまでは、立ち往生させない)。**施設で利用が終わって、帰り始める時は、毎回、今の道路で、帰りの経路を作り直す**。(行きの経路を逆向きに使うと、行った後に切られた道路を、歩き抜けてしまうため。切った時点で、まだ施設へ向かっていた住民が、これで守られる。元より長い経路なら、迂回として、同じペナルティ。)
- **満足度**: 住民に、独立した値(`satisfaction`、0〜100)を足した。今は、道路が無くなった時に下がるだけで、他の動きには、まだ影響しない。保存される。住民の情報パネルに、ゲージで出る。

## 見つけた問題と直し方
- 辺に触れるだけの範囲を、「切る」と判定していた(線が範囲の辺の上にある時、平行の判定が「内側」になっていた)。→ 平行で辺の上の時は、「交わらない」にした(テストで見つけた)。
- 施設へ向かう住民は、帰りの経路が、切った後に使えなくなっていても、気づかなかった(施設に着くまでは、経路が、切り口を通らないため)。→ 帰り始める時に、経路を作り直す。
- 切った後に、施設の中の住民が、帰れない時は、施設の位置のそばの安全な場所に、立ち往生させる。

## 確認したこと
- 単体テスト: スライス(始点からマスおき・端・短い端切れ・斜め・交差点・重複・隣り合う)・費用(5円/スライス・切り上げ・最低1円・合計してから切り上げ)・安全な位置・満足度・体力・切り口のメッシュ(延長しない)・セーブ(切り口の印の往復・古い形式)。
- ゲーム本体(診断用の一時コード。確認後に削除済み): 道路Aを切ると、外出し始めの住民が、迂回して帰る(満足度95・体力を消費・位置は飛ばない)/ 道路Bを切ると、向こう側の施設の中の住民が、立ち往生(満足度85)/ 施設から帰る住民も、切れた道を通らず、立ち往生 / 画面の位置から、道路のスライスを当てる・速いなぞりで、飛ばさず連続して選ぶ(6スライス = 30円)/ 払えない時は、全体を取り消す・払える時は、確定して、道路が切れる / セーブ→ロードで、切り口の印と、立ち往生が残る。画面で、切り口が平らで、隙間が塞がっていないこと・「立ち往生！」の札を確認。

## 追補(2026-10-28): スライスの境目・交差点・青マスの表示
- **交差点**: スライスの境目の上を通る、直角の道の中心線は、「交わる」と数える(隣り合う2つのスライスの、どちらを選んでも、その道の該当部分が切れる)。道路に沿った辺(幅の端)の上を通る線(隣の道の中心線)は、交わらない。
- **青マスの表示**: +Z向きに引いた道(yaw=0)の青マスだけ、描かれていなかった(登録はされていた)。そのため、ある向きに引いた道だけ、青マスが出ない・世界の格子線も、その分、消えて見えた。→ 全てのマスを描くようにした(`DrawOrientedGridOverlay`)。

## 追補(2026-10-28): 立ち往生からの復旧・解体ツールのお金の確認
- **復旧**: 立ち往生している住民は、3秒ごとの需要の更新で、「今の位置の近くの道路から、自宅(家が無ければ、元の家の位置)への経路」が、あるかを調べる。道がつながって、帰れるようになったら、位置はそのまま(経路の先頭が、今の位置)で、歩いて帰り始める(`TryRecoverStranded`)。満足度は、戻さない。
  - 立ち往生した位置は、建物の脇の安全な場所で、道路から離れていることがある。道路までの探索距離を、立たせた時の探索範囲ぶん、広げた。
- **お金の確認**: メニューの「解体」は、所持金が、解体の最小の費用(1円)に満たない時、押しても、ツールに入らず、メニューも閉じず、「お金が足りないので、選択できません」を、建築タブの下に出す(`MenuCommandType::NotifyBlocked`)。1円以上あれば、選べる。長さによる費用不足は、従来どおり。

## 追補(2026-10-28 その2): 立ち往生の場所・タイミング
- **タイミング**: 施設の利用中は、立ち往生させない。利用が終わって、帰り始める時に、帰りの経路を作り直し、帰れなければ、その時に、立ち往生する(`ReplanReturnRoute`)。歩いている住民は、これからの経路が切られて、帰れなければ、その場で立ち往生する。
- **場所**: 「何もない周辺の、安全な場所」ではなく、**道路の上**で立ち往生する。周りが建物だらけになっても、建物と重ならず、ワープもしない。今の位置が道路の上ならそのまま。切り取られた跡・施設の中なら、近くの、残った道路の上(施設なら、施設の接続点)へ寄せる(`BecomeStranded`。寄せる範囲は `strandedRoadSnapRadiusLegacyCells`)。そのため、「建物と重ならない安全な位置を探す関数」(`FindSafeStandingPoint`)は、不要になって、消した。

## Gate 3: 斜め・曲線・交差点で、見つけた問題と直し方
乱数で、スライスを、大量に選んで切る**性質テスト**(`cut_prop_test`。自由描きの曲線・斜めの直線・T字路・幅の違う6本の腕の交差点)を作り、毎回、次の性質が崩れないことを確かめた: 残った長さ+取り除いた長さ=元の長さ / 選んだスライスの中に、残った道路が入っていない / 短すぎる端切れ・孤立した短い切れ端が残らない / 切り口が、他の道路の端と、誤ってつながらない / メッシュの頂点が、有限で、範囲の外へ飛び出さない / 1スライスで、道が全部消えない。その上で、ゲーム内で、画面を保存して、目で確かめた。

1. **つなぎ目の隣を切ると、隙間が、見た目だけ塞がる**(画面で発見): T字路で、交差点のスライスを切ったのに、道が、つながって見えた。続きの区間の始点が、(つなぎ目が無くなって)行き止まりになり、**行き止まりの延長(0.5)が、切った隙間を、埋めた**。→ 切る前は、つなぎ目(2本以上が集まる点)だった端が、切った後に、行き止まり(1本)になったら、**平ら(flat)にする**(`CutRoads`の最後。点の一致は、座標の丸めで比べる)。性質テストにも、入れた。
2. **自由描きで、孤立した短い切れ端が残る**(画面で発見): 自由描きの区間(約0.8)は、スライス(0.5)で割り切れない。離れた2か所を切ると、間に、0.3ほどの切れ端が、どこにもつながらず残った。→ 切られた区間から出てきた切れ端のうち、**両端とも行き止まり(どこにもつながらない)で、スライスの7割(0.35)より短い物は、捨てる**(捨てた分も、取り除いた長さ=費用に入れる)。片方がつながっている切れ端、最初から孤立していた短い道は、触らない。
3. 確認して、問題が無かった物: 斜めの道(切り口が、道の向きに直角で、平ら。隙間・青マスも自然)/ 曲線(継ぎ目をまたぐ複数スライス。切り口は、区間の向きに直角)/ 幅の違う道が交わる交差点(切り取る長さは、交わる道の幅の分)/ セーブ→ロード(切り口の印・区間の数・青マスの数が、そのまま残る)。

## Gate 4: ドラッグでの連続解体・総合確認
操作の土台(押したままなぞって選ぶ・離して一括確定・重複なし・取り消し・費用表示)は、Gate 1〜2で作ってあった。Gate 4では、「途中で、おかしな状態になる」所を洗い出して、直した。

- **なぞる間の補間**: 前のフレームのカーソルから、今のカーソルまで、画面上で4ピクセルずつ刻んで、建物・道路のスライスを当てる(速く動かしても、飛び飛びにならない)。同じ建物・同じスライスは、何度なぞっても(戻っても)、1回だけ(集合)。
- **カーソルが、画面の外(ウィンドウの外)に出た時**: UIの上にいる時と同じ扱いに統一した(選びかけは、そのまま・新しくは選ばない・そこで離したら、取り消す)。
- **ドラッグ中に、別のウィンドウへ切り替えた時**(Alt+Tabなど): 入力は、フォーカスが無いと「押されていない」扱いになるため、「離した」と見分けがつかず、**意図せず確定してしまう**ところだった。→ `InputManager::HasFocus`を足し、フォーカスを失ったら、確定せず、取り消す。
- **ロード(F9)・タイトルへ戻る・Editingモードへ切り替え**: 選びかけを取り消す(前の街で選んだ位置が、新しい街に、残らない。道路のスライスは位置だけを持つので、残すと、別の道路を、切ってしまう)。
- **費用タグ**: 道路だけを選んでいる時は、切り取る長さを、マスの数で、一緒に出す(建物が混ざる時は、金額だけ)。
- **負荷**: 切り取りの計算に、窓と区間の、安い早期の除外を入れた。大きな街(1200区間)を、400スライス選んでも、1回の計算は約3ms(最適化なしの検証用ビルド)。毎フレーム呼ばれても、問題ない。
- Esc・右クリック(選びかけだけを先にやめる)・UIの上で離すと取り消す・お金が足りなければ全体を取り消す・建物と道路の混在、は、Gate 1〜2で作った通りに動く(ゲーム内の確認: 建物2棟+道路スライスを混ぜて選び、戻ってなぞっても数が増えない / ロードで、選びかけが消える / タイトルへ戻ると消える)。
