# 学習メモ: テストマップの自動検証の操作画面(段階3-B)

## 1. 何を作ったか
- Editor の「テストマップ」パネルに「自動検証」の欄を足した。一覧で選んだテストマップで、週数・回数・基準の種・決定論の確認を決めて、実行・中止し、進み具合と試行ごとの結果を見られる。
- 自動検証(と耐久試験)が街を進めている間は、建築・解体・編集など、街を変える操作を止めるようにした。

## 2. 用語
| 用語 | 意味 |
|---|---|
| ロック(操作の禁止) | ある間だけ、決まった操作を受け付けないこと。ここでは `IsWorldLocked()` が true の間 |
| 即時モードGUI(ImGui) | 毎フレーム、画面の部品を「描きながら」押されたかを調べる作り方。状態は、呼ぶ側(パネルのクラス)が持つ |
| `BeginDisabled` / `EndDisabled` | ImGui で、その間に描く部品を、灰色にして押せなくする。ウィンドウをまたいでも効く |
| 状態の要約(サマリー) | 長い画面の上の方に出す、短い状況の表示。下までスクロールしなくても、大事なことが分かる |
| バックバッファ | ゲームが描いた、画面に出す直前の絵。これを保存すると、他のアプリの画面を写さずに、ゲームの画面だけを撮れる |

## 3. 使った技術と、選んだ理由
### 3.1 画面は、結果を「読むだけ」
パネルは `SimEndurance` の進み具合・結果を読み、始める時は、ゲームが渡した関数(`Game::StartTestMapTrials`)を呼ぶだけ。
進める処理を画面に入れないので、段階7(画面を開かない無人実行)でも、同じ処理が使える。

### 3.2 パネルに渡す物を、1つのまとまりにした
```cpp
struct TrialAccess
{
    SimEndurance* endurance = nullptr;  // 進み具合・結果を読む・中止する
    TrialStarter start;                 // 始める(ゲーム側の関数)
    bool canStart = false;              // 今、始めてよいか
    const char* whyNot = "";            // だめな時の理由
};
```
引数を1つずつ増やすと、`Draw` の呼び出しが長く、間違えやすくなる。まとまりにしておくと、後で項目を足しても、呼び出しは変わらない。

### 3.3 操作の禁止を、2段構えにした
1. **入口で断る**: メニューでツールを選ぶ(`ApplyMenuCommand`)、素材を中央に置く、F5/F9。知らせを出す。
2. **毎フレーム、元に戻す**(`EnforceWorldLock`): 編集モードに入っていたら Playing へ戻す、選んでいたツールをやめる、エディタの選択を外す。
   → 実行を始める前から選んでいた物や、別の入口(エディタの Stop ボタンなど)から入った物も、取りこぼさない。
加えて、ツールの Update そのものを呼ばない。入口・毎フレーム・処理の3か所で止める。

### 3.4 異常で止まって見ている間(Held)は、止めない
耐久試験で異常が出ると、その状態を残して調べられる(Held)。この間に住民デバッグやエディタで調べたいので、ロックは「街を進めている間(Running)」だけにした。

### 3.5 下の方は見えない問題への対策
パネルが長く、自動検証の結果の表は、スクロールしないと見えない(段階2の確認で、保存ボタンが見つからなかったのと同じ)。
パネルの一番上に、短い状況(実行中は「何回目・何週目」と中止ボタン、終わった後は結果の要約)を出した。

## 4. 起きた問題と、直し方
| 問題 | 直し方 |
|---|---|
| 診断の画像で、結果の表がパネルの下にあって写らない | 診断の間だけ、`ImGui::SetScrollHereY` で表の所まで表示を送って撮った(確認後に削除) |
| 同じく、実際の操作でも、進み具合が見えにくい | パネルの上に、状況の要約を足した |
| 耐久試験のパネルが、自動検証の実行中に、耐久試験の設定での進み具合(週 / 26 など)を出してしまう | 自動検証の時は、「実行中です」と「中止」だけを出すようにした |

## 5. 確かめ方
ゲームの中の一時的な診断コード(確認後に削除)で、次を確かめた。画面はバックバッファを保存して見た。
- 実行中: 編集モードにしても、次のフレームで Playing に戻る / 建物・解体・道路・商業エリアのツールを選べない / 素材を置けない(物の数が変わらない) / 選んでいたツールがやめになる / F5が断られる
- 中止の後と、終わった後: ロックが外れ、建物のツールを選べる
- 26週×3回+決定論の確認: 結果4行、決定論の確認は「一致」
- パネルの表示: 待機中・実行中(進み具合の棒・中止)・結果(条件・決定論・表)が、エラーなく描ける

## 6. 気をつけること
- 新しく街を変える操作(ツール・パネル)を足したら、`IsWorldLocked()` の間に止めるか、必ず考える。
- ImGui の `BeginDisabled` は、閉じ忘れると、後の全部の部品が押せなくなる。必ず `EndDisabled` と対にする。
- 結果は、まだ画面に出すだけ。ゲームを閉じると消える(保存は段階4)。
