# エディタとアセット管理の使い方(全機能の解説)

このゲームの「エディタ」(デバッグ用のパネル群)と、素材(3Dモデル)を扱う機能の、**全ての使い方**です。
Unityのような画面構成で、素材をフォルダで整理し、サムネイルで見て、ゲームの画面へドラッグして置けます。

- 最終更新: 2026-10-21
- 設計の説明: [docs/design/asset_browser.md](../design/asset_browser.md)
- 使った用語・技術の勉強資料: [docs/study/](../study/)

## 1. 画面の構成(ドッキング)


起動すると、次のような配置で始まります。
```
┌ Editor メニュー(ウィンドウの最上端) ─────────────────────────────────────┐
│ 左上:Hierarchy │ 中央: ゲームビュー          │ 右: Inspector /          │
│ 左下:ツール群   │  ┌ ゲームのHUD(時刻・所持金)┐ │     Editor Settings      │
│  Debug/Build/   │  │ ゲームの絵はこの枠だけ   │ │                          │
│  Time/Economy/  ├──┴────────────────────────┴─┴──────────────────────────┤
│  Scenario       │ 下: Assets / Log / Profiler / City Stats(タブ)         │
└────────────────┴─────────────────────────────────────────────────────┘
```

- **パネルを動かす**: パネルの**タイトルバー(タブ)をドラッグ**します。他のパネルの上・下・左・右に重ねると**吸着**し、真ん中に重ねると**タブ**にまとまります。
- **大きさを変える**: パネルの境目(分割線)をドラッグします。
- **閉じる**: タイトルバーの **×**、または Editor メニュー > パネル のチェック。
- **配置は自動で保存**されます(`imgui.ini`)。次回の起動でも同じ配置です。
- **元に戻す**: Editor メニュー > **レイアウトを初期化**。
- 中央は**ゲームビュー**です。ゲームの絵(3D・HUD)は、この枠の中だけに描かれます。ここにはパネルを吸着できません(いつも空いています)。枠の上のマウス操作は、ゲームへ届きます(建物・道路の配置、オブジェクトの選択、カメラ)。
- パネルを**ドラッグできるのはタイトルバーだけ**です(スライダーなどの操作で、パネルごと動いてしまわないように)。

> ゲームビュー: ゲームの絵(3D・デバッグ線・HUD)は、中央の枠(ゲームビュー)の**中だけ**に描かれます。ゲームのHUD(時刻・所持金・人口)も、この枠の上端に入ります。枠の大きさを変えると、カメラの縦横比とHUDの配置が追従し、マウスの座標も、枠の左上を原点に読み替えられます(建物の配置・オブジェクトの選択・ギズモ・飾りの配置)。

## 2. Editorメニュー

画面の上部(HUDのすぐ下)の **Editor** をクリックします。

| 項目 | 内容 |
|---|---|
| **パネル ▸** | 全てのパネルの表示/非表示を、チェックで切り替えます。Hierarchy / Inspector / Editor Settings / Debug / Build / Time / Economy / Scenario / City Stats / Profiler / Log / Assets(F2)/ Asset Viewer / Shortcuts |
| **レイアウトを初期化** | 左・右・下のパネルの並べ方を、最初の配置に戻します。閉じたパネルも、初期の開閉に戻ります。 |
| **ヒントを表示** | ウィンドウの上にカーソルを置いた時の、キーのヒント(3章)のON/OFF。慣れたら消せます。 |
| **エディタ機能のON/OFF ▸** | 下の一覧のスイッチ。項目にカーソルを置くと説明が出ます。 |
| **ショートカット一覧...** | 全てのキー操作の一覧ウィンドウ(Shortcuts)を開きます。 |

**エディタ機能のON/OFF の一覧**(各システムが登録したスイッチ。増えると、ここに並びます)

| スイッチ | 内容 |
|---|---|
| 選択中のBoundsを表示 | 選択中のオブジェクトの当たり判定の箱(OBB)を描く(Editingモード) |
| 全てのBoundsを表示 | 全てのオブジェクトの当たり判定の箱を描く(Editingモード) |
| ドラッグでオブジェクトを動かす | OFFにすると、オブジェクト本体のドラッグ移動をしない(ギズモは使える) |
| 青マス(向きのチャンク)を表示 | 道路に揃って向きが確定したチャンクの境界・基準角度を描く(Playingモード) |
| 床の格子線を表示 | 地面のマス目の線を描く(青マスの線も含む) |
| モデルキャッシュを使う | OFFにすると、これから読むモデルを毎回ローダーで読み直す(9章) |

設定(パネルの表示/非表示・ヒントのON/OFF・上のスイッチ)は `Settings/editor.json` に自動で保存され、次回の起動でも保たれます。例外として、**Asset Viewer の開閉は保存しません**(中身が空では意味が無いので、いつも閉じて始まります)。

## 3. ヒントとショートカット一覧

### ホバーのヒント
**ウィンドウの上にカーソルを0.3秒置く**と、そのウィンドウの右下に、小さく `[キー] 説明` が出ます。

- Hierarchy・Build・Assets・Asset Viewer・Inspector などのパネルの上: そのパネルの操作。
- **ゲームの画面(中央)の上**: カメラの操作と、今のモード(Playing / Editing)の操作。
- ヒントは表示だけで、マウスやキーを奪いません。
- 慣れたら、Editor > ヒントを表示 のチェックを外して消せます(次回も消えたまま)。

### ショートカット一覧(Editor > ショートカット一覧...)
ヒントと同じ表を、場面ごとに全部並べたウィンドウです。

| 場面 | キー | 内容 |
|---|---|---|
| どこでも | F2 | Assets を開く/閉じる |
| どこでも | F5 / F9 | クイックセーブ / クイックロード(ゲームシーン) |
| どこでも | Esc / 右クリック | キャンセル(メニューを閉じる・配置の取り消し) |
| Playing | W A S D / 矢印 | カメラを平行移動(Shiftで速く) |
| Playing | ホイール | ズーム(カーソルの下の地面を中心に寄る・引く) |
| Playing | 中ボタンのドラッグ | 地面をつかんで動かす |
| Playing | 左クリック | メニューのボタンを押す / 建物を置く / 道路を引く・確定する |
| Playing | R | 建物の向きを回す(90度ずつ) |
| Playing | Esc | メニューを開く・閉じる(配置中は、配置をやめる) |
| Playing | 右クリック | メニューを閉じる / 配置をやめる(置きかけの道路が先) |
| Editing | 左クリック | オブジェクトを選ぶ / ギズモをドラッグ |
| Editing | W / E / R | 移動 / 拡大縮小 / 回転ギズモ |
| Editing | Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Editing | 右ドラッグ / 右ボタン+W A S D / Q・E / Shift | フリーカメラ(視点を回す / 前後左右 / 下・上 / 3倍速) |
| Editing | F | 選択中のオブジェクトへカメラを寄せる |
| Hierarchy | クリック | オブジェクトを選ぶ |
| Inspector | ドラッグ | 数値を変える(Ctrl+クリックで入力) |
| Assets | クリック | モデル・フォルダを選ぶ |
| Assets | ダブルクリック / V | ビューワーで開く |
| Assets | 右クリック | メニュー(ビューワー・場所を開く・パスをコピー) |
| Assets | フォルダをドラッグ | 別のフォルダの中へ移動 |
| Asset Viewer | 左ドラッグ / 中・右ドラッグ / ホイール | 回転 / 平行移動 / ズーム |
| Asset Viewer | 札をクリック | モデルの情報を見る |

(キーを変えた時は、`DebugTools/ShortcutTable.cpp` の表を直すと、ヒントとこの一覧の両方が変わります。)

## 4. Assets パネル(素材の一覧)

**F2** で開閉します(Editor > パネル > Assets でも同じ)。Unityの「プロジェクトウィンドウ」に当たります。
**軽い**ことが役目で、モデルを回して見るような重い処理はしません(それは6章の Asset Viewer の役目です)。
閉じている間は、何も処理しません。**初めて開いた時**に、素材のフォルダを探します。

### 4.1 探す場所
プロジェクトの中のフォルダだけです(絶対パスは使いません)。

| 場所 | 意味 |
|---|---|
| `Assets/Models/<パック名>/` | 採用した素材(Gitに入れる) |
| `Assets/Incoming/<パック名>/` | これから見る素材(**Gitに入れない**)。無ければ自動で作られる |
| `CityKitCommercial/`、`CityKitSuburban/`、`RoadTiles/`、`Models/` | 既存の素材(動かしていない) |

読めるモデルは、`.obj` と `.fbx` です。

### 4.2 画面の部品

**1行目**
| 部品 | 内容 |
|---|---|
| 検索 | 名前・パック名の一部で絞り込みます(大文字小文字は区別しません)。**選んでいるフォルダの中**を探します(全体から探すには、左の木で「すべて」を選びます) |
| サブフォルダも含める | ONなら、選んだフォルダの下のフォルダの中のモデルも出します(既定ON) |
| 重複も表示 | 同じモデルが OBJ と FBX の両方で入っている時、既定ではOBJだけを出します。ONで両方出します |
| 大きさ | 一覧のサムネイルの表示の大きさ(64〜192) |

**2行目(ボタン)**
| 部品 | 内容 |
|---|---|
| 再スキャン | フォルダを探し直します(エクスプローラーでファイルを足した後など) |
| サムネイルを作り直す | 今見えているモデルのサムネイルを、作り直します(テクスチャだけを変えた時など) |
| 生成を一時停止 | サムネイルの生成を止めます(重い時の確認用) |
| ビューワーで開く(V) | 選んだモデルを Asset Viewer で開きます。選んでいない時は、今見えているモデル全部を開きます |
| モデルキャッシュを消す | 9章 |

**本体**
- **左: フォルダの木。** 「名前 (モデルの数)」。クリックで選びます。右クリックのメニューと、ドラッグでの移動は5章。
- **右上: パンくず。** 「すべて > Assets > Models」のように、選んだフォルダまでの道。各階層をクリックで、その階層へ戻ります。
- **右: サムネイルの一覧。** 見えている行だけを描きます(何百件あっても軽い)。サムネイルは、見えている物が優先して作られます。
  - クリック: 選ぶ(橙の枠)。
  - **ダブルクリック**、または **V キー**(このパネルにカーソルがある時): ビューワーで開く。
  - **ドラッグ**: ゲームの画面へ落とすと、飾りとして置ける(7章)。
  - **右クリック**: メニュー。
    - ビューワーで開く
    - シーンの中央に置く(7章)
    - エクスプローラーで場所を開く(そのファイルを選んだ状態で)
    - パスをコピー
  - 何もない所での右クリック: 「見えているモデルをビューワーで開く」。
  - カーソルを置くと、パス・パック・形式が出ます。
- **下: 状況行。** `表示 N / 全M件`、サムネイル(待ち・作成・平均時間・キャッシュ読込・失敗)、モデルキャッシュ(ヒット・ミス・破棄・保存数・大きさ)。カーソルを置くと、最長・平均の時間も出ます。

### 4.3 サムネイルのキャッシュ
- 初回だけ、モデルを読んで絵にして、`Cache/Thumbnails/` に PNG で保存します。2回目以降は、画像を読むだけです。
- モデルのファイルが変わると(大きさ・更新日時)、自動で作り直されます。
- **大きなファイル(4MB超。街全体のFBXなど)は、自動では作りません**。サムネイルの場所に「大きいファイル / クリックで作成」と出て、クリックした時だけ作ります(数秒かかるため)。
- 作れなかったモデルは「x」と出て、再び試しません(「サムネイルを作り直す」で試し直せます)。

### 4.4 色について
サムネイルの光は、ゲーム内の時刻に関係なく、**昼の標準の光**で固定です。いつ作っても同じ見た目になります。

## 5. フォルダの整理(作成・名前の変更・移動)

実行中に、Unityのように、フォルダを作って素材を整理できます。
**できる場所は、`Assets/Models` と `Assets/Incoming` の下だけ**です。既存の素材フォルダ(`CityKitCommercial` など)は触れません。

| 操作 | やり方 |
|---|---|
| **新しいフォルダ** | 左の木で、`Models` や `Incoming`(またはその下)を右クリック > 新しいフォルダ。名前を入れて OK(Enterでも可) |
| **名前の変更** | 木でフォルダを右クリック > 名前の変更。`Assets/Models`・`Assets/Incoming` 自体は変えられません |
| **移動** | 木のフォルダを、別のフォルダへ**ドラッグ**。フォルダごと移動します(中のモデル・MTL・テクスチャの相対位置が保たれるので、参照は壊れません)。`Incoming` → `Models` へ動かすのが「採用」にあたります |
| エクスプローラーで開く | 木でフォルダを右クリック > エクスプローラーで開く |
| ビューワーで開く | 木でフォルダを右クリック > このフォルダをビューワーで開く(サブフォルダ込みで、全部のモデル) |

ルール:
- フォルダ名に使えるのは、**英数字・「_」・「-」・スペース**だけ。空・64文字超・先頭/末尾のスペース・Windowsの予約名(CON、NUL、COM1…)は不可。
- **個々のモデルファイルの移動・削除はしません**。MTLやテクスチャが、他のモデルと共有されていて、動かすと壊れるためです。**削除もしません**(エクスプローラーで行います)。
- 自分自身やその中へは移動できません。同じ名前が既にあると、移動・作成できません。
- **シーンに置いた飾り(Prop)が、そのフォルダのモデルを使っている間は、名前の変更・移動を止めます**(セーブ・ロードで、モデルのパスが合わなくなるため)。
- 失敗した理由は、下の状況行(赤)や、ポップアップの中に出ます。
- 作成・変更・移動の後は、自動で再スキャンされ、結果のフォルダが選ばれます。

## 6. Asset Viewer(モデルを並べて見る)

「モデルがどんな風に描かれるか」を確認するための、別ウィンドウです。**特定のフォルダやモデルを、一括で読み込んで**見られます。
普段は**閉じていて、何も読み込みません**(メモリも使いません)。

### 開き方
- Assets でモデルを**ダブルクリック**、または選んで **V**。
- 右クリックのメニュー、「ビューワーで開く(V)」ボタン、木のフォルダの右クリック(サブフォルダ込み)。
- 選んでいない時の「ビューワーで開く」は、**今見えているモデル全部**。

### 読み込み
- 渡された一覧を、**上限(既定64。ウィンドウの「上限」で1〜512)**まで、**1フレームに少しずつ**(8ms)読み込みます。読み込み中も操作できます。
- 上限を超える時は、`N 件のうち、最初の M 件だけ…` と警告が出ます。「上限」を上げて「再読み込み」で増やせます。
- **4MBを超えるファイルは、複数を開く時は省略**します(数秒、画面が止まるため)。「大きいファイルも読む」にチェックして「再読み込み」で読めます。1つだけ開く時は、読みます。
- 進み具合: `読み込み X / N(成功・失敗・大きいので省略) 合計 ms`。
- **閉じる(×)と、読み込んだモデルを全て解放**します。

### 表示と操作
- モデルは**格子状**に並びます(間隔は、1つぶんの大きさの約1.4倍)。各モデルは、中心を合わせ、最大の辺を揃えて描くので、単位や原点の位置がバラバラな素材でも、並べて比べられます。
- **左ドラッグ**: 回転 / **中ドラッグ・右ドラッグ**: 平行移動 / **ホイール**: ズーム。
- **全体表示**: 全部が見えるカメラに戻します。
- **名前の札**: 各モデルの上に出ます。「名前の札」のチェックで全部をON/OFF。札が混んでいる時(遠くから見ている時)は、選んだ札と、カーソルに一番近い札だけを出します。札はとなりのモデルまでの幅に収まるよう、末尾を切ります。
- **札の近く(60ピクセル以内)をクリック**: そのモデルを選び、下に情報を出します(形式・パック・頂点数・大きさ・**1x1マスに収める倍率**・ファイルサイズ・読み込み時間・テクスチャ・ライセンス文書)。
- **全部を背面から**: 全てのモデルを、Y軸まわりに180度回します(パックによって、正面の向きが逆なので)。
- **背景**: 背景の明るさ。
- **時刻**: その時間帯の光での見え方(ゲーム内の時刻とは無関係)。
- **再読み込み**: 同じ一覧を、今の設定(上限・大きいファイル)でもう一度読み込みます。

> 向きについて: Kenneyの建物は正面が +Z、SimplePoly の建物は正面が -Z です。サムネイルは斜め前(+Z側)から見るので、SimplePolyは裏側が見えます。ビューワーの「全部を背面から」で確かめられます。向きの補正は、建物として採用する時に行います(バックログ)。

## 7. 素材をゲームの画面へ置く(飾り=Prop)

### ドラッグ&ドロップ
1. Assets のサムネイルを**ドラッグ**します(プレビューの小さな札が出ます)。
2. **ゲームの画面(中央の透明部分)の上**へ動かします。地面に、**半透明のゴースト**と、**1マスの水色の枠**が出ます。
3. ボタンを離すと、そこに置かれます。

- 置く大きさは、**最大の辺が1マス**に自動で収まります(細長い物が巨大にならないよう、高さも含めた最大の辺で決めます)。足元が地面の高さに付きます。
- ゲームの画面でなく、パネルの上やHUDの上で離した時は、置かれません。地面が見えていない位置(Fieldの外、水平線の向こう)でも置かれません。
- 置いた物は **Prop** という種類のオブジェクトです。Hierarchy に `[Prop]` と出ます。位置・向き・大きさの調整は、**Editingモード**で、Hierarchy/Inspector/ギズモ(W/E/R)で行います。
- **マスを占有しません**。道路や建物と重なって置けます(飾り・目印用)。
- Playing / Editing のどちらでも置けます。

### 右クリックで置く
Assets のサムネイルを右クリック > **シーンの中央に置く**。ゲームの画面の中心の地面へ置きます。カメラが水平に近くて、中心の先に地面が無い時は、**フィールドの中心**へ置きます。

### セーブ・ロード
- **F5 / F9**(クイックセーブ・ロード)、Scenarioパネルのセーブ・ロードで、飾りも保存・復元されます。
- 保存されるのは、**モデルのパス(プロジェクト相対)・位置・回転・拡大**だけです。ロード時に、同じモデルを読み込んで置き直します。
- 古いセーブ(飾りの項目が無い)も、そのまま読めます(飾りは0個)。
- モデルのファイルが無くなっていた飾りは、**警告を出して飛ばし**ます(落ちません)。
- 他の人からもらったセーブデータの飾りのパスが、絶対パスや `..` を含む場合は、その飾りだけ飛ばします(PCの任意のファイルを読ませないため)。
- 飾りがあるフォルダは、名前の変更・移動ができません(5章)。

## 8. エクスプローラーから素材を取り込む(ドロップ)

ゲームの**ウィンドウの上へ、エクスプローラーからファイルやフォルダをドロップ**すると、`Assets/Incoming/` へ**コピー**して取り込みます。元の場所のファイルは、動かしません・消しません。

### 規則
- **フォルダをドロップ**: `Assets/Incoming/<フォルダ名>/` へ、中身を再帰的にコピー。
  - コピーするのは、**使う拡張子だけ**: モデル(`.obj .fbx`)、`.mtl`、画像(`.png .jpg .jpeg .tga .bmp .dds`)、説明書き(`.txt .md .html .pdf`)。
  - `.blend`、`.zip` など、重くて使わない物は飛ばし、**飛ばした数と大きさ**を報告します。
- **ファイルをドロップ**: モデル(`.obj/.fbx`)を `Assets/Incoming/Dropped_<日時>/` へ。
  - **OBJ**: MTLと、MTLが参照するテクスチャ(map_Kd・bump など。オプション付きも)を、**相対位置のまま**一緒にコピー。
  - **FBX**: 同じフォルダの画像と、同じ場所の `Textures` フォルダの中の画像を、一緒にコピー。
  - 複数のファイルを同時にドロップした時は、同じ `Dropped_<日時>` にまとめます。
  - モデルでない単独のファイル(画像だけ、など)は、取り込みません。
- **同じ名前のフォルダがあれば、`_2`、`_3`…** を付けます(上書きしません)。
- フォルダ名は、使える文字(英数字・`_`・`-`・スペース)に直します。日本語だけの名前(例: 「ダウンロード」)は、`Imported` になります。
- **合計が1GBを超える物は、取り込みません**(使う物だけ別のフォルダに分けて、もう一度ドロップしてください)。
- **ファイルの中の名前(MTL・テクスチャの参照)は変えません**。そのため、プロジェクトが使う文字コード(Windowsのシステムの文字コード)で表せない名前のファイルは、**飛ばして**報告します。
- ドロップされた物が、既に `Assets/Incoming` の中にある場合は、取り込みません(自分自身へのコピーの防止)。
- ドロップされたフォルダの**外**にあるMTL・テクスチャは、取り込めません(警告が出ます)。

### 取り込んだ後
1. 自動で、Assets が開き、**取り込んだフォルダが選ばれ**、サムネイルの生成が始まります。
2. **「取り込み結果」のウィンドウ**が出ます。件数・大きさ・飛ばした物・**「ライセンスを確認して THIRD_PARTY_LICENSES.md に記録してください」**。「OK」か、「エクスプローラーで開く」。
3. 詳しい注意(飛ばした理由など)は、Logパネルに出ます。

> ゲームを**管理者として実行**していると、通常の権限のエクスプローラーからのドロップは、Windowsに拒否されます(ドロップできません)。管理者でなく起動してください。
> 大きな素材のコピー中は、数秒、画面が止まることがあります(コピーはゲームの更新の中で行うため)。

## 9. モデルキャッシュ(2回目から軽くする仕組み)

一度読んだモデルを、**ディスクに「焼いて(bake)」保存**し、次回からは、それを読むだけにする仕組みです。OBJの文字の読み取り・FBXの解析・座標系の変換・色の変換を飛ばせるので、**読み込みが軽くなります**。
モデルを読む全ての場所(ゲーム起動時、サムネイル、ビューワー、飾り)が、同じ入口を通るので、**全部が速くなります**。

- 保存先: `Cache/Models/<名前>_<キー>.mesh`。Gitには入りません。消しても、次の読み込みで作り直されるだけです。
- 中身: **重複のない頂点の表**と、**インデックス**。三角形ごとに頂点を並べる形より、ディスクの大きさが**約4分の1**になります。
- **自動で作り直される**条件(キーが変わる): モデルのファイルの大きさ・更新日時が変わる、同じフォルダの `.mtl` の大きさ・更新日時が変わる(色を変えた時)、キャッシュの版(`BakedModelCache::kVersion`)が変わる。
- **捨てて作り直す**条件: ファイルが壊れている・短い・版が違う・チェックの値が合わない・保存時にあったテクスチャが今は無い。
- 保存に失敗しても(ディスクが満杯など)、読み込み自体は成功します。保存は一時ファイルに書いてから置き換えるので、途中で落ちても壊れません。
- Assets の下の状況行に、**ヒット・ミス・破棄・保存数・大きさ**が出ます。「モデルキャッシュを消す」ボタンで、全部消せます。
- Editor > エディタ機能のON/OFF > **モデルキャッシュを使う** で、OFFにできます(これから読むモデルを、毎回ローダーで読み直す)。
- **実測**(Release): 6600頂点のOBJ 6.1ms → 0.44ms、26100頂点 21ms → 1.7ms、31476頂点 26ms → 1.9ms(約12倍)。FBX(3756頂点) 2.5ms → 0.45ms(約5倍)。Debugビルドで、ビューワーに41モデルを読み込む時間: 約14.9秒 → 約0.39秒。

注意(割り切り):
- **ローダーの出力の意味を変えた時**(座標系の変換・色の変換・テクスチャの探し方など)は、`BakedModelCache::kVersion` を上げてください。上げないと、古い内容のキャッシュが使われ続けます。
- **FBXに、テクスチャを後から足した時**(保存時にテクスチャが無かった場合)は、キャッシュに「テクスチャ無し」が残ります。「モデルキャッシュを消す」で直ります。
- テクスチャの画像のデコードは、キャッシュしません(モデルは、画像のパスだけを持ちます)。
- ゲームを動かしている間に MTL を書き換えても、その起動中は検出しません(フォルダごとの MTL の目印を、起動中は覚えているため)。再起動で反映されます。

## 11. 素材を使うまでの流れ(ライセンスの運用)

1. **取り込む**: 新しい素材パックを、エクスプローラーからゲームの画面へドロップ(8章)。または、`Assets/Incoming/<パック名>/` へ置いて「再スキャン」。
2. **見る**: Assets のサムネイルで一覧し、Asset Viewer で並べて、描かれ方を確認する。
3. **ライセンスを確認する**: 取得元のページ・同梱の文書で、**使える範囲(商用・改変・再配布)・クレジットの要否・AI学習の禁止などの条件**を確認し、**`THIRD_PARTY_LICENSES.md` に記録する**(入れる前に。チェックリストが末尾にあります)。
4. **採用する**: 使う物だけを、木のドラッグで `Assets/Incoming/...` から `Assets/Models/...` へ移す(5章)。
5. **使う**: ゲームの画面へドラッグして飾りとして置く(7章)。建物として使う場合は、建物の定義(`BuildingType.cpp`)にモデルのパスを書く。
6. **再配布できない素材**(例: SimplePoly City)は、元ファイルをそのままGitに入れない(`.gitignore` に追加する、または、専用形式に変換した物だけを入れる)。

- **ゲームの画面を、中央のウィンドウの中に分離すること**(Unityのゲームビュー)。バックログに記録。

## 13. うまくいかない時

| 症状 | 原因・対処 |
|---|---|
| Assets に素材が出ない | `Assets/Incoming/<パック>/` などに置いて、「再スキャン」。拡張子が `.obj/.fbx` か確認。重複の判定で隠れている時は「重複も表示」 |
| サムネイルが「x」 | モデルを読めなかった(Logパネルに理由)。ファイルが壊れている・非対応の中身(スキニングなど)。 |
| サムネイルが「大きいファイル」 | 4MB超。クリックで作成(数秒止まります) |
| サムネイルが暗い・色が変 | 「サムネイルを作り直す」。色の扱いを変えた版では、自動で作り直されます |
| ドロップしても何も起きない | 管理者として実行していないか。ゲームのウィンドウの上へドロップしているか |
| ドロップしたが「取り込めませんでした」 | メッセージの理由を確認(上限超え・モデルが無い・名前の文字コード・既にIncomingの中) |
| 飾りが置けない | ゲームの画面の上で離したか(パネル・HUDの上は不可)。地面が見えているか(水平線の向こうは不可)。右クリックの「シーンの中央に置く」でフィールドの中心へ置ける |
| フォルダの名前を変えられない・動かせない | `Assets/Models` と `Assets/Incoming` の下だけ。シーンの飾りが使っていないか(使っていると止まります)。同じ名前が無いか |
| ヒントが出ない | Editor > ヒントを表示 のチェック。カーソルを0.3秒止める。ゲームのHUDの上では、ゲーム画面のヒントは出ません |
| パネルが消えた・配置が崩れた | Editor > レイアウトを初期化(または、`imgui.ini` を消して再起動) |
| モデルの見た目が古い | 「モデルキャッシュを消す」 |

## 14. カメラ(Playing=実際に遊ぶ状態 / Editing)

カメラは、モードで動かし方が変わります(モードの切り替えは、Debug パネルの Play / Stop)。

### Playing(街づくり。exeで遊ぶ状態): 平行移動とズーム
シミュレーションゲームによくある、見下ろしのカメラです。**平面の移動**と**ズーム(縮尺)**の2つで動かします。向きと見下ろす角度は固定です。

| 操作 | 内容 |
|---|---|
| W A S D / 矢印キー | 平行移動(奥・手前・左・右) |
| Shift を押しながら | 速く動く(約2.5倍) |
| マウスのホイール | ズーム。**カーソルの下の地面が、画面の同じ場所に残る**ように、寄る・引く |
| 中ボタンのドラッグ | 地面を**つかんで**動かす(つかんだ点が、カーソルに付いてくる) |

- 移動の速さは、引くほど速くなります(画面での動く速さが、ズームによらず一定)。
- ズームは、4(一番寄る)〜40(一番引く)の距離の範囲。注視点は、フィールドの範囲(+余白2)から出られません。
- 動きは、なめらかに追いつきます(急に止まらない)。
- **ゲームシーンが始まる時**は、フィールドの中心を見下ろす最初の見え方になります。**EditingからPlayingへ戻る時**は、フリーカメラの今の視点を引き継ぎます(視点が飛びません)。
- パネルやHUDの上のホイール、文字を入力している間のキーでは、カメラは動きません。
- ゲームのウィンドウが前面にない時は、キー・マウスのボタンを読みません(別のアプリで打ったキーで、カメラが動かないように)。
- 数値(角度・距離の範囲・速さ・なめらかさ)は、`Core/CityCameraController.h` の `CityCameraSettings` で調整できます。

### Editing: フリーカメラ
オブジェクトの編集用に、自由に飛び回れます。右ドラッグで視点を回し、右ボタンを押しながら W A S D / Q・E で動かします(Shiftで3倍速)。F で、選んだオブジェクトへ寄ります。Playingでは、このフリーカメラは動きません。

## 15. ゲーム内メニュー(建物・道路を選ぶ)

Playing(実際に遊ぶ状態)で、建物や道路を選ぶ画面。カイロソフトのゲームのような、メニューのボタンから選ぶ形。Editingでは出ない。

### 開く・閉じる
- **右下の「メニュー」ボタン**を押す、または、**何も選んでいない時に Esc**。開くと、**ゲーム内の時間が止まる**(上のHUDの時刻が進まない)。
- 開いている間は、右下のボタンが「戻る」になる。「戻る」・Esc・右クリックで閉じる。閉じると、時間が動き出す。
- 開いている間は、後ろの街をクリックしても何も起きない。カメラも動かない。

### 左の項目(タブ)
| 項目 | 中身 |
|---|---|
| 建築 | 左の列=建物(住宅・オフィス・コンビニ・スーパー・映画館・カフェ。値段つき)。右の列=道路(細い道・ふつうの道・広い道。1マスの値段つき)と、引き方(直線 / 自由描き)。オフィスは、仕事の概念を停止しているので、建てられるだけで何も起きない。施設のモデルは暫定 |
| 情報 | 日付(1年目 1月 第1週)・所持金・人口・住民(需要が不足の人数)・住宅/施設の数・今週/先週/今月の来客と売上 |
| 研究 | 準備中 |
| システム | セーブ / ロード(F5 / F9と同じ)。直前の結果が下に出る |
| オプション | 音量(全体・BGM・効果音)。0〜100。下の「オプション(音量)」を参照 |

### オプション(音量)
左の「オプション」を押すと、**全体・BGM・効果音**の音量を、0〜100で調整できる(100が最大、0で無音)。全体は、BGMと効果音の両方にかかる。同じ行に、3通りの調整が並ぶ。
- **スライダー**: つまみをドラッグ(押した所へ、つまみが動く。つかんだまま、カーソルが外へ出ても追う)。
- **-5 / +5**: 押すたびに5ずつ変わる(0と100で止まる。端では押せない)。
- **数字の欄**: 押すと入力モードになり(欄に _ が出る)、**数字キー(テンキーも)で0〜100を入力 → Enter で決定**。Backspaceで1文字消す。Esc(または、ほかの所を押す)でやめる。入力中は、Esc・右クリックでも、メニューは閉じない。101以上を入れると100になる。
変えた音量は、すぐに音へ反映され、**自動で `Settings/audio.json` に保存**される(次の起動でも保たれる。スライダーをつかんでいる間・入力中は待って、終わってから保存する)。ファイルを消すと、全て100に戻る。

### 建物・道路を置く
1. 建築で、置きたい物を押す。**メニューが閉じて、時間が動き出し**、ゴースト(半透明の見本)が出る。
2. 街をクリックして置く(道路は、2点をクリック、または、自由描きはドラッグ)。同じ物を、続けて何度でも置ける。Rで、建物の向きを回す。
3. 払えない時は、値段が赤くなる(押して選ぶことはできる)。置こうとすると、カーソルの横に「お金が足りません」と出る。
4. 左下の「建築中: 住宅 [やめる]」の「やめる」、または、**右クリック・Esc**で、配置をやめる。置きかけの道路がある時は、先に、その置きかけをやめる(もう一度で、配置自体をやめる)。
5. 何も選んでいない状態でEscを押すと、またメニューが開く。

### 開発用のBuildパネル
ImGuiの「Build」パネルは、そのまま残している(開発用)。ツールは、None / Building / Road。起動した時は、None(何も置かれない)。

### 見た目の差し替え
メニューとHUDの見た目は、「スキン」という1か所にまとめてある。画像素材に差し替える手順は、[ui_skin.md](../design/ui_skin.md)。

## 16. タイトル画面

起動すると、タイトル画面が出ます。背景は、初期マップ(`Scenarios/tutorial.json`)の街で、カメラが街のまわりをゆっくり回ります(約78秒で1周)。昼夜の光も、少しずつ変わります。
- **スタート**(ボタン、または Enter キー): ゲームを始めます。
- **終了**(ボタン): ウィンドウを閉じて、ゲームを終わります。
- どこをクリックしても始まる、ということはありません(ボタンを押した時だけ)。
- ゲームのタイトル(今は「街づくりゲーム」)は、`UI/TitleMenu.h` の `kDefaultTitle` の1行を変えると替わります。
- ボタン・タイトルの板の見た目は、HUD・ゲーム内メニューと同じスキンです(後で画像に差し替えられます)。
- エディタのパネル(Hierarchy・Log など)も、一緒に映ります。不要な時は、Editor メニューでパネルを閉じてください。

## 17. DebugビルドとReleaseビルドの違い

- **Debug**: 開発用。エディタ(Unity風のパネル・Editorメニュー・Assets・ログなど)が付く。
- **Release**: 実行用。**エディタのパネルは出ない。** タイトル画面・ゲーム内のHUD・メニューだけで、最後まで遊べる。デバッグ用の線(建物と道路の接続線・向きのチャンクの線)も出ない。格子線は、建物・道路を置こうとしている間だけ出る。
- Releaseでの操作の違い: フリーハンドの道路は、引いた後に、**クリック(またはEnter・Space)で確定**、右クリック・Escで取り消す(Debugでは、カーソルの横の「確定/取消」ボタン)。F5・F9のクイックセーブ/ロード、メニューのセーブ/ロードは、Releaseでも使える。

## 18. 実行環境(ダブルクリックで動くフォルダ・zip)を作る

別のPCに渡して、`GAME.exe` のダブルクリックだけで動かせる、実行用のフォルダと zip を作ります。
```
.\tools\make_release_package.ps1            (Releaseをビルドして、作る)
.\tools\make_release_package.ps1 -NoBuild   (今ある x64\Release\GAME.exe で作る)
```
- 出力: `dist\GAME\`(フォルダ)、`dist\GAME.zip`(約0.8MB)。`dist` は Git に入れません。
- 中身: `GAME.exe`、シェーダー(`*.hlsl`・`Lighting.hlsli`)、使うモデルとテクスチャ、初期マップ(`Scenarios`)、音(`Sounds/sounds.json` と **`Sounds/sounds.pak`**)、ライセンス、`README.txt`(起動・操作の説明)。
- **音は、mp3 のまま入れません**。BGMの素材の規約が、「音源のファイルを、そのままの形で配ってはいけない」ためです。`tools\pack_sounds.ps1` で、`Sounds/*.mp3` を `sounds.pak` にまとめて入れます(`make_release_package.ps1` が自動で行います)。配布物に mp3・wav が残っていると、スクリプトが止まります。詳しくは docs/design/audio.md §14。
- 必要な環境: Windows 10 / 11(64bit)、DirectX 11対応のGPU。C++のランタイムは exe に組み込み済みで、別のインストールは要りません。使うDLLは、全て Windows 標準です。
- 日本語のフォントは、Windows標準のもの(メイリオ等)を使います。
- 署名の無い exe のため、Windowsが警告を出すことがあります(「詳細情報」→「実行」。README.txt にも書いてあります)。
- セーブ(`Saves`)・モデルのキャッシュ(`Cache`)は、exeの隣に作られます。書き込める場所に置いてください。

### 開発する時の注意
- Release の exe は、**素材(`SimpleShader.hlsl`)がある場所**を、exe のフォルダから上へ最大4段探して、見つかった所で動きます。配布用のフォルダ(`dist\GAME`)は exe の隣、開発中の `x64\Release\GAME.exe` は、プロジェクトのフォルダが見つかります。どこから起動しても、同じです。
- Debug(開発用)は、従来どおり、プロジェクトのフォルダの素材を読みます(Visual Studio から、そのまま動きます)。
- 使うモデル・シェーダーを増やした時は、`tools\make_release_package.ps1` の一覧に足してください(足し忘れると、渡した先で起動しません)。


## 19. Audio パネル(音の一覧と音量。Debugビルドのみ)

Editor メニューの「パネル」から「Audio」を開く(最初は閉じている。下のタブにドッキングされる)。音の一覧を見て、音ごとの音量を数字で調整し、試し聴きできる。

### 上の段: 全体の音量
全体・BGM・効果音の音量(0〜100)。ゲーム内メニューの「オプション」と**同じ値**を動かす(どちらで変えても同じ。自動で `Settings/audio.json` に保存)。数字の欄(+/-ボタン・直接入力)とスライダー、「ミュート」のチェックがある(ミュートは保存されない・試す用)。

### 音の一覧(表)
| 列 | 内容 |
|---|---|
| 試聴 | 「Play」で鳴らす。曲(BGM)は「Stop」で止める(今のタイトルの曲に切り替わるので、試した後は止めるか、タイトルへ戻る) |
| id | ゲームのコードが呼ぶ名前(`Sounds/sounds.json` の `id`) |
| 種類 | BGM / SE |
| 音量(%) | **音ごとの音量**。数字(+/-ボタン、クリックして直接入力)。100=素材のまま。**最大200**(素材が小さい時に持ち上げる)。0〜200 |
| スライダー | 同じ値を、スライダーで(Ctrl+クリックで、数字を入力) |
| ファイル / 属性 | 音のファイル、タグ、ループ・ストリーミング・距離で減衰、の印 |

- 変えた音量は、**すぐ反映される**(鳴っている音にも効く)。試聴の大きさは、「全体」「種類」の音量も掛かる。
- 音ごとの音量は、**「音の表に保存」を押すまで、ファイルには書かれない**。押すと `Sounds/sounds.json` へ書き戻す(書き込み中に落ちても元の表が壊れないよう、一時ファイルに書いてから置き換える)。下に「未保存の変更があります」/「保存済み」が出る。
- 「全体・BGM・効果音」(プレイヤーの設定)と「音ごとの音量」(素材のばらつきをそろえる値)は別物。最終の大きさは、**全体 × 種類 × 音ごと** を掛けたもの。


## 20. 住民の外出・施設・週(City Stats パネル。Debugビルドのみ)

住民(1軒に1人)は、生活・アクティビティの需要(0〜100。80以上で充足)と体力を持ち、不足すると(または、自発的に)、道路でつながった施設へ出かけて利用する。使った分の売上は、集計され、**売上の100%が所持金に入る**(試作の設定)。詳しい仕組みは [docs/design/resident_outing.md](../design/resident_outing.md)。

### 利用履歴と立ち寄り(P1)
- 住民は、直近に使った施設を覚えていて、**同じ施設に続けて行きにくく**なる(別の施設の方が選ばれやすい。ただし、他に行ける施設が無ければ、同じ施設に行く)。不足している日用品を買いに行く時は、あまり避けない。
- 主目的の施設を使い終わると、**低い確率(約25%。2回目は約10%)で、近くの別の施設に寄ってから**帰る(最大2回)。寄った施設でも、需要が回復し、売上が出る。体力が足りない・遅い時刻・遠い時は、寄らない。
- カフェを使った後に、別のカフェへ寄るのは、めったにない。
- City Stats の **Decisions** に、立ち寄りの選択(`[stop #1]`)と、候補ごとの「repeat x」(履歴による重みの倍率)が出る。Settings の「利用履歴(P1)」「立ち寄り(P1)」で、確率などを変えられる(試す時は、立ち寄りの確率を上げると、見やすい)。

### 週
朝6時〜夜10時が活動時間(実時間で約120秒)、そのあと就寝(約10秒)。就寝に入る瞬間が「週末」(需要が自然に減る・ペナルティの判定・週の集計の区切り)、朝が来ると次の週。4週で1か月、12か月で1年。HUDの時刻の横に「1年目 1月 第1週」。時間の倍率(Timeパネル)を上げると、早く試せる。

### 試し方
1. 道路を引き、住宅と、施設(コンビニ・スーパー・映画館・カフェ)を、**道路のすぐ隣**に置く(道路に接していない施設は、使われない)。
2. しばらく待つと、住民が道路を歩いて、施設へ行く。施設に着くと、中に入って(見えなくなる)、しばらくして、帰る。
3. メニューの「情報」で、今週の来客と売上、所持金の増え方が分かる。

### City Stats パネルのタブ
| タブ | 内容 |
|---|---|
| Summary | 住宅・施設・住民の数、需要が不足の人数、今週・先週・今月・通算の来客と売上 |
| Facilities | 施設ごとの来客と売上(今週・先週・今月・通算) |
| Residents | 住民ごとの、需要・体力・ペナルティの段階・特徴・直近の選択。需要が不足(80未満)の数字は、オレンジで出る |
| Decisions | 外出を決めた時の、**全候補の道のり・重み・確率・除外の理由(到達不可/体力不足)・選ばれたもの**(新しい順) |
| Settings | 仮の数値(確率・体力・ペナルティ・選び方の係数・売上が資金に入る割合・乱数の種)。実行中に変えられる(保存はしない。初期値は `Simulation/ResidentSimSettings.h`) |
- Inspector で住民(Agent)を選ぶと、その住民の状態・需要・体力・特徴・直近の選択が出る。

### 住宅をクリックして、住民の情報を見る(ゲーム内)
1. 何も置いていない状態で、**住宅を1回クリック**すると、選ばれる(黄色い枠)。
2. **同じ住宅を、もう1回クリック**すると、「住民の情報」パネルが開く(需要・体力・ペナルティ・特徴・直近の選択・最近の利用)。
3. パネルが開いている間は、**ゲーム内の時間が止まる**。「閉じる」・パネルの外のクリック・Esc・右クリックで閉じると、時間が動き出す。
- 何も無い所をクリックすると、選択が外れる。コンビニなど、住宅以外は、選ぶだけ(今は情報パネルは出ない)。
- 建物・道路を置く操作を始めると、選択は外れる。

### 住民を追跡して、住民の情報を見る(ゲーム内)
1. 何も置いていない状態で、**住民(歩いている小さな人)を1回クリック**すると、**追跡**に入る(カメラが住民を追う。足元に黄色い輪。左下に「住民を追跡中」)。小さいので、当たり判定は、少し大きめ。
2. **追跡中の住民を、もう1回クリック**すると、その住民の「住民の情報」パネルが開き、時間が止まる。
3. 追跡をやめるには、**Esc・右クリック・何も無い所をクリック**。WASD・矢印・中ボタンのドラッグでカメラを動かしても、やめる。住民が施設や家の中に入っても、追跡は続く。

### クリックの当たり判定を見る(Debugビルドだけ。Releaseでは見えない)
デバッグ用の機能で、既定はOFF。**F3**(または Editor > エディタ機能のON/OFF >「クリックの当たり判定を表示」)で、建物(水色)・住民(ピンク。少し大きめ)のクリックできる範囲の箱が出る。もう一度で消える。Releaseビルドには、この機能は入っていない。
(選択した建物の足元の黄色い四角・追跡中の住民の足元の黄色い輪は、ゲームの表示で、Releaseにも出る。当たり判定の箱ではない)
以前からある「選択中のBoundsを表示」「全てのBoundsを表示」(Editor メニュー)も、**Playing中にも**使える(モデルそのままの箱で、住民の余白は含まない)。

### 左ボタンのドラッグで、カメラを動かす
何も置いていない時は、**左ボタンを押したまま、カーソルを動かす**と、地面をつかんで動かせる(WASD・矢印・中ボタンのドラッグも、そのまま使える)。**動かさずに離す**と、クリック(建物・住民の選択)になる。
左ボタンのドラッグは、カーソルの動きの **0.75倍** だけカメラが動く(感度を少し下げてある。中ボタンのドラッグは、つかんだ地面がカーソルにぴったり付いてくる)。変えるには、Core/CityCameraController.h の leftDragScale(1で、ぴったり)。
- 動かしたと見なすのは、押した位置から6ピクセルより離れた時(それより小さい動きは、クリック)。
- 建物・道路を置いている最中(メニューで選んだ後)は、左ボタンは、配置に使うので、カメラは動かない(Esc・右クリックで配置をやめれば、また使える)。
- 建物・住民の選択は、ボタンを**離した時**に決まる。

## 21. 住民デバッグ(Editorのパネル。Debugビルドのみ)

住民を1人選んで、**今の状態・判断の理由(計算の内訳)・処理の履歴・異常**を読むパネル。「立ち寄りが起きない理由」「なぜその施設が選ばれたか」を、目で見て確かめるためのもの。**Releaseには出ない。パネルを開いても、ゲーム内の時間は止まらない。** 仕組みは [docs/design/simulation_debug_system.md](../design/simulation_debug_system.md)、解説は [docs/study/simulation_debug_system.md](../study/simulation_debug_system.md)。

### 使い方
1. Debugビルドで、街を作る(住宅と施設を道路の隣に置く)。時間の倍率(Timeパネル)を上げると、記録が早く溜まる。
2. ゲームの画面で、**住民を1回クリック**(追従が始まる)、または、**住宅を1回クリック**(その住宅の住民)。「住民デバッグ」パネルが、その住民に切り替わる。もう1回クリックすると、これまでどおり、ゲーム内の「住民の情報」パネルが開く(時間が止まる。これは別のパネル)。
3. パネルは、既定では、下のタブ(City Stats の隣)に入っている。見当たらなければ、Editor メニュー > パネル で「住民デバッグ」にチェック、または、レイアウトの初期化。
4. 上の段:
   - **記録する**: ONの間だけ、判断・状態の変化を記録する(ONでもOFFでも、ゲームの動きは変わらない)。
   - **固定(Pin)**: ONの間は、別の住民・住宅をクリックしても、表示を切り替えない。
   - **住民を選ぶ**: 一覧から選ぶ(住宅の中にいて見えない住民も選べる)。
   - 記録の使用状況(件数・約KB・捨てた件数)。上限(イベント20000件・判断の内訳2000件)を超えると、古い物から捨てる(件数と、残っている一番古い番号を出す)。
   - 何も選ばずに、地面をクリックしても、**最後に見た住民は残る**。ロード・リセット・タイトルへ戻ると、選択は外れる。

### タブ
| タブ | 内容 |
|---|---|
| 現在 | 住民ID・住宅(有無)・状態・位置・直近の判断/行き先・目的・立ち寄り回数/滞在の残り/需要・体力(ゲージ。不足は表示)・ペナルティ・満足度・特徴/経路(進み具合・残りの道のり)/**次の外出判定**(1回の確率と、その理由。直近の判定の乱数・連続の不発の回数。就寝中・遅い時刻・施設なしの時は、その旨)/最近使った施設(再訪補正の対象) |
| 判断の詳細 | 施設選び1回を選んで(コンボ)、判断した時の状態・目的の決定(乱数)・**候補の表**(道のり・採否・基本の重み・再訪倍率・最終の重み・選択確率・抽選の範囲・結果)・**抽選の乱数と合計**・食事系の連続・**日本語の計算式**(表の行をクリックで、その候補の式に切り替え)。「判断した時の設定」は、スライダーを後で動かしても変わらない |
| 処理履歴 | この住民の記録を、**外出ごとのまとまり**(外出判定 > 目的選択 > 施設選択 > 移動 > 到着 > 利用 > 立ち寄り判定 > 帰宅)で。**灰=普通の不成立(確率・条件)、黄=注意(解体・迂回・立ち往生など、設計上ありえる)、赤=確認された異常、緑=成功**。判断のある行の[詳細]で、判断の詳細タブへ移る。「不成立も出す」「注意と異常だけ」で絞れる |
| 異常 | 今、違反している条件と、検出した異常(全住民。新しい順。[この住民を見る]で切り替え)。赤い帯が、パネルの上にも出る |

### 異常として検出するもの(確認された条件の破れだけ)
値がNaN/Inf・体力が負/住民の基準を超える・需要が0〜100の外・満足度が範囲外・ペナルティが負・立ち寄り回数が負・移動中の経路の添字が外・向かっている/利用中なのに行き先が無い・家の参照が壊れている・住居なしなのに家のidがある。「確率に外れた」「ペナルティで体力の上限が体力より低くなった」などは、異常ではない。

### 立ち寄りの確認のしかた(例)
- 住民を選び、「処理履歴」で、利用完了の次の行を見る。`立ち寄り1回目の抽選に外れた(確率 25.0% ≦ 乱数 0.xxxx)` なら、**抽選の外れ**(普通)。`立ち寄りを考えない: 時刻が遅い/体力が足りない/回数が上限` なら、条件で考えなかった。
- 当選した時は、`立ち寄り1回目の抽選に当選` → 目的選択 → 施設選択([詳細]で、候補の表と計算式)。`範囲外`・`今回使用済み`・`体力不足` などの除外の理由が、候補ごとに出る。
- 試す時は、City Stats > Settings で「1回目の立ち寄り確率」を上げると、見やすい。

### 注意
- 記録は、**ロード・リセットで消える**(別の世界になるため)。保存はしない。
- 行動の強制は、下の「行動テスト」。統計は、まだ無い(段階4以降)。履歴を読み返す機能(シークバー)は、下の「履歴を読み返す」。

### 履歴を読み返す(住民デバッグ。シークバー)
パネルの上の方に、**ライブ / 履歴**の切り替えと、**シークバー**がある。
- **ライブ**(緑の文字): 最新のイベントを追う。**履歴**(黄色の文字): 過去の1つのイベントを固定して読む。履歴を見ている間、新しいイベントが来ても、表示は動かない。**「現在の街は巻き戻っていません」**(街は、そのまま進む。止まっていれば、止まったまま)。「ライブに戻る」で戻る。別の住民に切り替えると、ライブに戻る。
- **シークバー**: ドラッグで、この住民の、記録されたイベントを1つずつ選ぶ。バーの上の黄・赤の目印は、注意・異常のイベントの位置、下の黄色い三角は、ブックマーク。
- **移動のボタン**: 先頭 / 前 / 次 / 最新(ライブ) / 前の外出・次の外出 / 前の注意・異常・次の注意・異常 / 前のブックマーク・次のブックマーク。「処理履歴」の行をクリックしても、そのイベントを見られる。
- **履歴で見える物**: 「現在」タブは、そのイベントに残した、**その時点の状態**(状態・住宅・行き先・体力・需要・満足度・ペナルティ)。位置・経路・滞在の残りは、記録していないので、出ない。「判断の詳細」は、その時点の判断に合う。
- **絞り込み・検索**: 文字の検索(イベントの種類・説明)、不成立(灰)を隠す、注意(黄)と異常(赤)だけ。ブックマークは、隠れない。
- **ブックマーク**: 「ブックマークする」で、見ているイベントに目印を付ける。「ブックマーク一覧」(全住民)から、その住民・そのイベントへ移れる。ロード・リセットで消える。
- **古い記録が、上限で捨てられた**時は、見ていたイベントが、一番古い物に寄って、その旨が出る。

### 一時停止の条件(イベントが起きたら、ゲームを自動で止める)
パネルの「一時停止の条件」を開く。
- 「確認された異常(赤)で止める」「注意(黄)以上で止める」「止めるイベントの種類」(複数)+「上の種類のうち」(成功のとき・不成立のとき…)。対象は、全住民 / 今の住民だけ。
  - 例: 種類=**立ち寄り判定**、結果=**成功のとき** → 立ち寄りの抽選に当選した瞬間に止まる。
- 条件に当てはまると、**シミュレーションの1回分の更新が済んだ所で、ゲーム内の時間が止まる**。パネルの上に「一時停止中: 住民 #n のイベント #m で、止まりました」と出て、そのイベントが履歴として開く(固定(Pin)中は、別の住民へは切り替わらない。「このイベントを見る」で切り替えられる)。
- **[再開]** で、元の倍率で、また進む。止まっている間に、メニューを開いて閉じても、止まったまま。
- 条件は、記録がONの間だけ働く。起動のたびに、条件はOFFに戻る(保存しない)。Releaseでは、止まらない。

### 行動テスト(住民に、意図した行動を実行させる)
住民デバッグパネルの「**行動テスト**」タブ。「この住民に外出してもらって、立ち寄りが起きるか見たい」を、確率に頼らず試すための道具。
1. **行動を選ぶ**: 外出させる / 立ち寄りを当選させる / 帰宅させる / 行き先を変える / 体力を決める。
2. **どこまで強制するか**(外出・立ち寄りの時): 「通常ルール」=確率の抽選だけを当選にする(施設は、普通の抽選で選ぶ)/「施設を指定」=指定した施設を選ぶ(除外された施設なら、拒否される)。外出の時は、「外出の後、立ち寄りも当選させる回数」も選べる。
3. **誰に**: 今見ている住民 / 範囲(ワールドのXZ座標の四角。実行ボタンを押した時の位置で選ぶ。「今見ている住民の周り」「広い範囲」のボタンあり)/ 全住民。一度に実行する人数の上限(既定50)。
4. **実行**: 11人以上には、確認の画面が出る。実行すると「待機中」になり、**次の安全なタイミング**(外出判定・立ち寄り判定・更新の最初)で、1回だけ実行される。夜に出した外出指示は、朝まで待つ。「直近の実行を取り消す」で、待機中・実行中の指示を外せる(済んだ行動は、戻らない)。
5. **結果**(新しい順): 成功 / 拒否 / 取消 / 期限切れの数と、一覧。拒否は、通常ルールに合わなかった理由(家にいない・外出中でない・施設が除外された・体力不足・立ち寄りを考えない条件など)で、**異常ではない**。[#n 履歴]で、その時のイベントへ移る。
- 強制した住民のイベントには、処理履歴に **`[テスト#n]`** が付く(普通の行動と区別できる)。
- **注意**: 強制した行動の結果(来客・売上・所持金・満足度)は、本物のプレイと同じように、街に反映される。**元に戻す機能は無い**(乱数の状態も戻らない)。やり直したい時は、先に **F5でセーブ**しておく。
- 同じ住民に、待機中の指示がある間は、新しい指示は出せない。外出が始まった後(実行中)は、新しい指示で置き換えられる(外出させた後に、「帰宅させる」「立ち寄りを当選させる」を続けて試せる)。
- 食事系が続く時の「寄らない」判定は、強制しない(拒否になる)。

## 22. 住居なしの住民を、新しい住宅に入れる(ゲーム内)
- 住宅を解体されると、住んでいた住民は「住居がない！」になって、元の場所に立つ。
- **新しい住宅を建てる**と、住居がない住民がいる時だけ、「**入居する住民を選ぶ**」画面が出る(開いている間は、時間が止まる)。
  - 一覧から、**入居させる住民をクリック**。その住民は、今いる所から歩いて、新しい家へ向かう(道が無ければ、道がつながるまで、その場で待つ。この時、満足度は下がらない)。
  - **誰も選ばない**時は、「**新しい住民を迎える**」(またはEsc・右クリック)。新しい住宅に、新しい住民が生まれる(住居がない住民は、そのまま残る)。
  - 一覧が長い時は、「前へ」「次へ」でページを送る。住宅を続けて建てた時は、1軒ずつ、順番に出る。
- この画面は、Releaseでも出る(ゲーム内のUI)。
- 試し方: 住宅を1軒建てて住民が出るまで待つ → 解体ツールで、その住宅を解体(住民が「住居がない！」になる)→ 住宅を建てる。

## 23. 建物を解体した後の青マス
建物を置くと、その敷地のマスが、青マス(建物を置く目印。「青マスを表示」で見える)に登録される。**解体すると、その建物が使っていた青マスも消える**(道路の脇の青マスと、他の建物が使っているマスは、残る)。
